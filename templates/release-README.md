## 5 刷写步骤

1. 备份原厂系统（见下）。
2. 进 MaskROM。
3. 送 loader。
4. 整盘写入镜像。
5. 首次启动、冷启动 ≥3 次验证。

```bash
# 示例，按实际工具调整
sudo rkdeveloptool list
sudo rkdeveloptool db <loader>.bin
sudo rkdeveloptool wl 0x0 <image>.img
```
