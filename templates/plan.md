# <整机名> Linux 适配实施计划

> **性质**：执行清单。只写"现在要做什么、怎么验、失败怎么退"。
> **冻结**：**先出草案，经用户确认后定稿**；定稿后只有用户提出或批准才能改，
> 每次改动在文末「修订记录」追加一行。日常进展、临时发现、失败尝试写会话日志，不写本文件。
> 过程写会话日志，进度写进度页，本文件不承载细节。

- **版本**：YYYYMMDD（第 N 版）
- **状态**：草案（待确认） / 已定稿（YYYY-MM-DD 用户确认）
- **对象**：<整机名> / <主板丝印> / <SoC>
- **范围**：<做哪些、不做哪些>
- **依据**：可行性分析、board-profile
- **红线**：破坏性操作由人执行；电源/GPIO 改动人肉复核；不代提交 git
