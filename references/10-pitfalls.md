# 10 坑清单

> 只收**机制通用**的坑：换一块 RK 板仍可能遇到。板子特有的结论请写进你自己的 board-profile，
> 不要往这里加。
>
> 记法：**现象 → 原因 → 对策**。

## 观测

1. **上电零输出** → 串口电平/波特率/终端时序三件事之一 → 先量 TX 空闲电压；负压是 RS-232，
   必须用 USB-RS232；波特率先试厂端值；**先开终端再上电**。
2. **U-Boot 有、内核静默** → `verbosity=1` 让 loglevel 只剩紧急消息；`console=tty1` 排在最后；
   earlycon 没开 → 查 cmdline 三件事，别先怀疑 UART。
3. **earlycon 加了仍静默** → 8250 earlycon 默认按时钟 1.8432 MHz 算 divisor，
   高波特率下算成 0 → 第 4 字段显式给时钟。
4. **HDMI 黑屏判"没启动"** → DRM 是模块且无 simpledrm 时，framebuffer 只在 initramfs 阶段存在 →
   用"串口 + 画面"双通道，别用截图代替全文。

## 电源 / PMIC / 复位

5. **照抄参考板电源树 ⇒ 没电源** → PMIC 挂的总线/中断脚/使能脚因板而异 → 一律以厂端 dtb 为准；
   参考板只用来学写法。
6. **整片 LDO 不注册** → 某个没用的控制器默认 pinmux 占了 PMIC 中断脚 → 不用的控制器默认关，
   一条一条开。
7. **USB 口没电但 `lsusb` 正常** → 使能脚 bank/极性错 → 判据用 VBUS 实测 + 块设备，
   改完看 `debug/gpio` 是否被 claim。
8. **`regulator-fixed` 替换 `gpio-hog` 后冷启动枚举退化** → 使能时机不同（always-on 与早期 claim
   不等价）→ 要换表达先解决"启用时机"，并用冷启动 ×3 验证。
9. **换 bootloader 后 PHY 认不到** → 复位脚没人释放，或时钟父节点缺失 → 复位写在控制器节点
   （驱动要在枚举 PHY 前拉），父时钟有几个写几个。
10. **`gpio-hog` 在部分内核不生效** → 静默无 claim、无报错 → 别把 hog 当"提前拉脚"的可靠手段。
11. **改电源/GPIO 后上电异常** → 极性或电压写错会伤硬件 → 电源使能类改动人肉复核后再投放。

## 存储 / SDIO

12. **声明 `sd-uhs-sdr104` 但 IO 固定 3.3 V** → 主线要切 1.8 V，卡不应答 → CMD11 超时或无块设备 →
    不要声明板子做不到的速率/电压。
13. **日志被 `vcc_sdio: voltage operation not allowed` 刷屏** → `vqmmc` 指向固定电压轨，
    每次重扫都要切档 → 删掉该引用（功能通常不受影响）。
14. **"eMMC 没有分区表"被当驱动故障** → 可能本来就是 Rockchip 私有布局，LBA0 全零 →
    先读 LBA0 与磁盘末尾再判断。
15. **厂端内容与固件包偏移不一致** → 板上内容可能整体后移 → 写之前先核现场，别照抄固件包。
16. **TF 卡时认时不认** → 供电可能"半开"（栅极电压不足，处于亚阈值）→ 万用表定这种模糊态；
    卡检测二选一（控制器 CDETECT 或 `cd-gpios`）。

## 网络

17. **`NO-CARRIER` 就改 delay** → 真因可能是网线/对端 → 顺序永远是物理层 → 时序 → 供电。
18. **`rgmii` + 厂端 delay 抄来就丢包** → 参数未必适配本板 → 首发用 `rgmii-id` 且不写 delay，
    不通再退厂端组合，一次只调一个方向。
19. **`apt` 卡住 / DNS 坏 / 普通用户不能 ping** → 三件独立的事：只解析到 IPv6、`resolv.conf`
    悬空软链、缺 `cap_net_raw` → 先 `ping <公网 IP>` 判断外网，再查 DNS。
20. **厂端 U-Boot 一次上电只允许一次网络传输** → 下完一个文件网络就死 → 拼单文件 payload，
    一次取走；注意 initrd 格式与地址间隔。

## 启动 / rootfs / 镜像

21. **`root=UUID=` 挂不上** → 内核早期没有 UUID 分支，UUID 依赖 initramfs → 用 PARTUUID 或设备名。
22. **第一次启动成功、第二次掉 initramfs** → 首启扩容重建分区，GUID 变了 → 补丁写回原 GUID，
    或改用不依赖 GUID 的写法；判据必须是冷启动 ≥2~3 次。
23. **首启扩容吃掉 userdata 与 backup GPT** → 开关语义可能是"看文件内容" → 装配镜像时显式关掉；
    扩完不可逆。
24. **设备端写完不 `sync` 掉电丢文件** → rootfs 可能 `commit=600` → 要留的写入之后 `sync`。
25. **内核升级后起不来** → 升级会重建 `/boot/dtb`，自建 dtb 被冲掉 → 加 postinst 钩子补回。
26. **镜像工具链的坑** → 备份镜像的 backup GPT 在文件外（`sfdisk` 误报 dos）；旧 `e2fsck` 不认新特性；
    WSL 挂载遮住 `/mnt`；Windows 裸写物理盘会改写 GPT 头；某些 GUI 只导出固定大小。

## 判定 / 流程

27. **灯不亮/键不响应就改 dts** → 厂端遗留节点会被当成本板的 → 每颗灯要有"GPIO + 极性 +
    default-state"三件套的实测依据。
28. **dmesg 里 N 条错误 = N 个问题** → 计数是下限，旧噪声要有白名单 → 判据是"零新增"。
29. **改了参数没生效** → 多行粘贴被拼成续行、参数没进 cmdline、引号被 shell 吃掉 →
    每次改完回读（`/proc/cmdline`、env 文件、dtb 属性）。
30. **外设"不工作"就怀疑内核** → 先分三层：驱动 probe / mixer 或默认配置 / 用户态 →
    很多"驱动问题"其实是默认值。
31. **"千兆上不去"** → 先确认硬件链路能力（变压器、网线、对端）→ 再谈 PHY 配置。
32. **自编内核 vermagic 相同却载不进模块** → 工具链版本不同导致结构体布局差异 →
    自编内核可作为证据，发布版优先用官方内核。
33. **软复位挂死、冷启动正常** → 复位路径/ATF 版本问题 → 判据用断电冷启动；偶发挂死记录观察，
    不要为它改 dts。

## 测量陷阱

34. **带坏块的 U 盘/U 盘线** → 会刷大量 IO 错误，误判板级回归 → 换件 A/B。
35. **`hwclock -r` 超时** → 可能是读失败而不是"读到错误时间" → 看退出码与 `dmesg`。
36. **万用表档位/表笔位置** → 测"半开"这类状态时，档位和落点决定结论 → 记录测量点。
